# Security Policy

This package makes authorization decisions. Please treat any bug that grants access it should not as a security issue.

## Reporting a vulnerability

Do not open a public issue. Email **im@ricardovargas.me** with:

- the package version,
- a minimal reproduction (profile rules, assignment, the check that returned the wrong answer),
- the impact you expect.

You will get a reply within 5 working days. Fixes ship as a patch release with a note in `CHANGELOG.md`.

## Supported versions

Only the latest minor release receives security fixes.
